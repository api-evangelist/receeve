# Receive (Receeve) Client API

> Receeve is a no-code debt collection and receivables-management SaaS platform (founded in Hamburg, backed by Speedinvest, acquired by InDebted and now operating as the "Receive" product). The Receive Client API is an OpenAPI 3.0 REST API secured with OAuth2 client-credentials (Bearer tokens) that manages accounts, claims, debtors, ledger entries, dunning journeys, multi-channel communications, hosted debtor landing pages, promises-to-pay, instalment plans and settlements, and emits a large catalog of signed webhook events.

## APIs
- [Receive Client API reference](https://api.receeve.com/api-reference): Interactive Scalar reference (46 operations across Account, Claim, Journey, Message, LandingPage, Finance and Files domains).
- [Canonical OpenAPI spec](https://receive-api.indebted.co/openapi/apiSchema.yaml): OpenAPI 3.0.3, version 1.53.1.

## Authentication
- [Authentication use case](https://docs.indebted.co/docs/receive/integration/use-cases/authentication-use-case): OAuth2 client-credentials — POST /v1/oauth2/token with HTTP Basic client_id:client_secret, receive a Bearer access_token (expires_in 3600s), send it as `Authorization: Bearer <token>`.
